ExercicioDeAssociacao

A Java exercise to practice **associations between classes** in Object-Oriented Programming. It models a small academic scenario where professors, students, seminars and locations relate to each other.

 💻 About the project

This project was created to practice how objects relate to each other in Java: a seminar has a location, is taught by a professor and is attended by students. Everything runs in the terminal, and a test class creates the objects, links them together and prints the result.

✨ Features

- **Classes and relationships:**
  - Aluno: represents a student.
  - Professor: represents a professor, who can be linked to seminars.
  - Seminario: represents a seminar, connecting professor, students and location.
  - Local: represents the place where a seminar happens.
- Test class: AssociacaoTeste creates the objects, associates them and prints the information.
- Overloaded constructors: objects can be created with different sets of information.

 🚀 Technologies

- Java (Standard Edition)
- Object-Oriented Programming (OOP)
- Associations between classes
- Arrays of objects
- Encapsulation (private attributes)

▶️ How to run

1. Clone the repository:

git clone https://github.com/MicaelMoras/ExercicioDeAssociacao.git
2. The files use package ExercicioDeAssociacao;, so keep them inside a folder with that name.
3. From the parent folder, compile and run:

javac ExercicioDeAssociacao/*.java
java ExercicioDeAssociacao.AssociacaoTeste
